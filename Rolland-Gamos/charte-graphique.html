04 //

SYSTÈME AVATARS

  • Format — 64 × 64 pixels
  • Vue — Buste face (tête + épaules)
  • Fond — Transparent (PNG)
  • Style — Flat colors, zéro dégradé
  • Ombrage — 2 à 3 valeurs max par teinte
  • Anti-aliasing — Interdit
  • Distinctifs — Lunettes, coiffure, accessoires forts
  • Lisibilité — Prioritaire sur le détail
  • Marge — Minimale autour du personnage

EFFETS VISUELS

VALIDATION RÉPONSE Flash vert + particules montantes
ERREUR / MAUVAISE RÉPONSE Flash rouge + tremblement UI
ACTIVATION JOKER Éclair violet + onde de choc

CHANGEMENT DE TOUR Balayage horizontal bleu
DOMINATION / STREAK Aura feu + texte ON FIRE !

CONTRAINTES EFFETS

  • Style pixel art strict — pas de particules réalistes
  • Ne pas ralentir le jeu — optimisation prioritaire
  • Lisibilité permanente — jamais de surcharge visuelle
  • Palette validée — rouge / orange / violet / bleu / or
  • Durée courte — max 0,5s pour les effets d'action
  • Cohérence — même logique sur tous les modes
